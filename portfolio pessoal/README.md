# Luan Biagioni — Developer Portfolio

Portfólio técnico para programadores: aesthetic terminal/IDE, stack em backend · fullstack · blockchain.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173).

## Personalizar

Edite **`src/data/portfolio.ts`**:

- Nome, email, links (GitHub, LinkedIn)
- Domínios e tecnologias
- Projetos (títulos, descrições, links reais)

## Deploy

```bash
npm run build
```

A pasta `dist/` pode ir para Vercel, Netlify, GitHub Pages, etc.

## Stack

- React 19 + TypeScript
- Vite 6
- CSS puro (sem dependência de UI kit)
